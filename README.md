# QscriptNt

## Что такое QscriptNt?
QscriptNt - Это компилируемый язык программирования с простым синтаксисом

## Как скачать?

1. Зайти в релизы и скачать последний.
2. Установить всё через удобный инсталлер
3. Или самому собрать инсталлер (читать readme.txt)

## Команды qsr

- `qsr update` - обновление локального списка библиотек
- `qsr create <name>` - создать новый проект
- `qsr install <proj> <name>` - установка библиотеки
- `qsr out` - скомпилировать проект
- `qsr build` - сборка через компилятор
- `qsr run` - собрать через FASM + запуск
- `qsr info` - информация о qsr
